# Trendium downloads

Official Windows installers for [Trendium](https://trendium.cc), the crypto market-reading app.

**Get the latest version:** [Releases](https://github.com/sofinityx/trendium-downloads/releases/latest), or from the [Microsoft Store](https://trendium.cc).

Each release lists the installer's SHA-256 fingerprint, so you can check your download matches.

This repository only holds installers; it contains no source code. For help, see [trendium.cc/support](https://trendium.cc/support/).

Trendium is an educational market-awareness tool. It does not provide financial advice, trading signals or trade execution.
